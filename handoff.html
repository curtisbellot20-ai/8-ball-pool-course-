△ How to Deploy on Vercel
1
Go to vercel.com and log inSign up with your GitHub account so Vercel can access your repos.
2
Click “Add New → Project”Then click “Import Git Repository” and select 8-ball-pool-course-.
3
Set the branchUnder Branch, choose claude/ball-pool-website-0QKtT. Leave all other settings as-is.
4
Click DeployVercel builds and hosts your site. You’ll get a live URL like https://8-ball-pool-course.vercel.app
5
From now on it’s automaticEvery time Claude pushes a change to GitHub, Vercel redeploys within seconds. No manual steps needed.
🤖 How to Make Changes with Claude Code

You don’t need to touch any code. Just open Claude Code and tell it what you want.

1
Open Claude CodeAt claude.ai/code or in your IDE (VS Code, etc.).
2
Say exactly what you wantExamples: “Change the Pro price to $127”  •  “Update my bio to say [your text]”  •  “Add my Amazon link to the cue card”  •  “Add a new section for FAQs”
3
Claude edits the code and pushes to GitHubIt handles everything — you just review and confirm.
4
Vercel deploys automaticallyYour live site updates within 30–60 seconds of Claude pushing the change.
🔒 Important Notes
Affiliate DisclosureThe site already includes a legal affiliate disclosure in the gear section and the footer. You’re covered once you add your real links.
30-Day GuaranteeThe pricing section shows a 30-day money-back guarantee. Make sure your payment platform (Gumroad, etc.) is set up to honor refunds before going live.
Course Platform RecommendationGumroad is the fastest to set up (free, 10 minutes). Teachable or Kajabi offer more features if you want a full learning management system with video hosting.
Custom Domain on VercelIf you have a custom domain (e.g. thecluefoundation.com), you can connect it in Vercel under Project Settings → Domains. Ask Claude Code to help if needed.
